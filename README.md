# 🚀 TechPrep Matrix - Technical & Management Interview Prep Platform

An interactive, high-performance web application designed to master interview questions across **8 core technical and management domains**:

1. 🤖 **Android** (Jetpack Compose, Kotlin, Coroutines, MVVM/MVI, Memory Leaks, Hilt)
2. 💙 **Flutter** (Dart, Riverpod, BLoC, Widget/Element/RenderObject trees)
3. 🍊 **SwiftUI** (Swift, @StateObject, Actors, Concurrency, ARC retain cycles)
4. 📊 **Project Management** (Agile/Scrum, Scope Creep, Velocity, Cycle/Lead Time, Risk Management)
5. 🎯 **Product Management** (RICE/Kano Prioritization, PRDs, North Star Metrics, Cohort Retention, GTM)
6. 🍃 **Spring Boot** (Java, Auto-configuration, Spring Security, JPA/Hibernate N+1 problem)
7. 🟢 **Node.js** (Event Loop phases, libuv, Streams backpressure, Worker Threads vs Child Process)
8. ⚡ **Full Stack** (System Design & Base62 URL shortener, OWASP Security, JWT Cookie Auth, Scalability)

---

## ⚡ Quick Start

### Option 1: Using the Startup Script (Recommended)
Run the executable shell script from your terminal:

```bash
chmod +x start.sh
./start.sh
```

This will automatically launch a local HTTP server on port `8080` and open `http://localhost:8080` in your default browser!

On Windows, you can double-click `start.bat` or run:
```cmd
start.bat
```

### Option 2: Opening Directly in Browser
You can open `index.html` directly in any modern browser (Chrome, Safari, Firefox, Edge).

## ✨ Features

- 📚 **Comprehensive Q&A Bank**: Deep model answers, interview takeaways, and code snippets.
- 🎴 **Interactive Flashcards**: Flip cards, rating system, and keyboard shortcuts (`Space` to flip, `←` `→` to navigate).
- 🔍 **Real-Time Filtering & Search**: Instant query search, difficulty filter (Junior, Mid, Senior, Lead), and bookmarking.
- 📥 **Export to Markdown**: Download your custom study guide for offline reading.
- 🌙 **Dark/Light Theme**: Seamless aesthetic toggle.
- 💾 **Progress Persistence**: Bookmarks and mastered states automatically save to `localStorage`.
